Headings Mobile Testing Guide

How to test heading hierarchy, landmark regions, and skip links using VoiceOver on iOS and TalkBack on Android. Use alongside the Headings and Landmarks Playground: test the same scenarios on a real device using these steps.

⚠️ Mobile testing requires a physical device. Xcode Simulator and Android Emulator do not accurately simulate VoiceOver or TalkBack gesture behaviour.
iOS · VoiceOver

VoiceOver on iPhone and iPad

Before you start:
  • Enable VoiceOver: Settings → Accessibility → VoiceOver → Toggle ON
  • Or add to Accessibility Shortcut: triple-click the side button
  • Use Safari. VoiceOver + Chrome heading navigation is unreliable
  • Open the page you want to test in Safari

1
Broken heading hierarchy
WCAG 1.3.1
Scenario from Playground page, Scenario 1
1
Open the page in Safari. Enable VoiceOver.
2
Open rotor: rotate two fingers. Rotate until Headings is announced.
3
Swipe down to move to the next heading. Swipe up to move back.
4
Listen to what VoiceOver announces for each heading: it says the level and the text. For example: "Heading level 2, Latest articles."
Expected failure: VoiceOver announces "Heading level 1, Page title" then "Heading level 3, Latest articles": the level 2 is missing. Then "Heading level 1, About this site": a second H1. The sequence is illogical and confusing.
2
Visual heading not marked up
WCAG 1.3.1
Scenario from Playground page, Scenario 2
1
Open rotor, set to Headings.
2
Swipe down through all headings. Count how many VoiceOver announces.
3
Now set rotor back to default (characters or words). Swipe right through all elements and listen for the section title text.
Expected failure: Rotor Headings mode shows only "Our services" (H2). The "Strategy and Consulting" and "Training and Enablement" sections are completely absent from the heading list. VoiceOver reads them as plain text when swiping through all elements: no heading level announced.
3
Missing main landmark
WCAG 1.3.1
Scenario from Playground page, Scenario 3
1
Open rotor, rotate to Landmarks.
2
Swipe down to navigate between landmarks. Listen for what VoiceOver announces.
Expected failure: VoiceOver finds no "main" landmark. The content area is not reachable via landmark navigation. The user must swipe through every element on the page to reach the main content.
4
Multiple unlabelled nav landmarks
WCAG 1.3.1
Scenario from Playground page, Scenario 4
1
Open rotor, rotate to Landmarks.
2
Swipe down through landmarks. Listen to what VoiceOver announces for each nav.
Expected failure: VoiceOver announces "navigation" twice with no distinguishing label. The user has no way to know which is the main navigation and which is the breadcrumb.
What correct looks like: VoiceOver announces "Main navigation, navigation landmark" and "Breadcrumb, navigation landmark": distinct labels for each.
Android · TalkBack

TalkBack on Android

Before you start:
  • Enable TalkBack: Settings → Accessibility → TalkBack → Toggle ON
  • Or hold both volume keys for 3 seconds
  • Use Chrome
  • Open the page you want to test in Chrome

1
Broken heading hierarchy
WCAG 1.3.1
Scenario from Playground page, Scenario 1
1
Open the page in Chrome with TalkBack enabled.
2
Open reading controls: swipe up then right. Swipe right until Headings is selected. Double-tap to confirm.
3
Swipe right to move to the next heading. Swipe left to go back.
4
Listen to what TalkBack announces: it says the heading level and text. "Heading level 3" after "Heading level 1" with no level 2 in between is the failure.
Expected failure: TalkBack announces H1, then jumps to H3 (level 2 absent), then another H1, then H4 (levels 2 and 3 absent). The hierarchy is broken and navigation is disorienting.

Visual heading not marked up

Scenario from Playground page, Scenario 2
1
Set reading controls to Headings.
2
Swipe right through all headings. Note how many are announced.
3
Switch back to default navigation (Characters). Swipe through the section and listen for the styled div text: no heading level is announced.
Expected failure: Only "Our services" (H2) appears in heading navigation. "Strategy and Consulting" and "Training and Enablement" are invisible to heading navigation: TalkBack reads them as plain text only.

Open TalkBack menu: swipe down then right.
2
Select Navigation by landmarks. Swipe right to navigate between landmarks.
Expected failure: TalkBack finds no main landmark. The primary content area is unreachable by landmark navigation alone. The user must swipe through every element to find it.

5
Correct structure: the passing example
WCAG 1.3.1 · 2.4.1
Scenario from Playground page, Scenario 6
1
Set reading controls to Headings. Navigate through all headings.
2
Navigate by landmarks. Listen for distinct landmark labels.
Expected pass: H1 → H2 → H3 → H3 → H2: sequential, logical. Landmarks: "Main navigation", "Breadcrumb", "main": all distinct and navigable. Structure reflects the visual layout.
