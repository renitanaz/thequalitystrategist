14 A11y Alt Text Mobile Testing Guide

How to test alt text failures on iOS VoiceOver and Android TalkBack. Use alongside the Alt Text Playground: same scenarios, tested on a real device.

⚠️ Physical device required. Simulators do not reliably replicate how VoiceOver and TalkBack announce image content.
iOS · VoiceOver

VoiceOver on iPhone and iPad

Before you start:
  • Enable VoiceOver: Settings, Accessibility, VoiceOver, Toggle ON
  • Open the Alt Text Playground in Safari
  • Use the rotor to navigate by Images for efficient scanning
Essential gestures for image testing

Playground Scenario 1
1
Open the playground in Safari. Enable VoiceOver.
2
Open rotor, set to Images. Swipe down to navigate to Scenario 1's image.
3
Listen to what VoiceOver announces.
Expected failure: VoiceOver announces the data URI or a partial filename: no meaningful description. The user has no idea what the image shows.
2
Filename as alt text
Playground Scenario 2
1
Navigate to Scenario 2's image using the rotor Images mode.
2
Listen carefully to the full announcement.
Expected failure: VoiceOver announces "I M G underscore 2 0 2 4 1 1 0 3 underscore 0 9 4 5 1 2 dot j p g, image": the filename read character by character. Meaningless and disorienting.
3
Decorative image not suppressed
Playground Scenario 4
1
Set rotor to default (Characters or Words). Swipe right through the paragraph, image, and paragraph in Scenario 4.
2
Count the number of announcements between the two paragraphs.
Expected failure: VoiceOver announces "decorative wave divider, image" between the two paragraphs: interrupting the reading flow for a purely visual element. Should be alt="" so VoiceOver skips it silently.
4
Functional image: alt describes appearance
Playground Scenario 5
1
Navigate to the cart icon link in Scenario 5 by swiping right.
2
Listen to what VoiceOver announces. Ask: do you know where this link goes?
Expected failure: VoiceOver announces "shopping cart icon, link": the appearance is described but not the destination. The user cannot decide whether to tap it.
Correct: VoiceOver should announce "Go to checkout, link."
5
Correct alt text: all three types
Playground Scenario 8
1
Navigate through all three images in Scenario 8 using rotor Images mode.
2
Listen to what VoiceOver announces for each.
Expected pass: Meaningful image announces the full revenue data. Decorative image is skipped entirely: VoiceOver jumps straight to the next element. Functional image announces "Go to checkout, link."
Android · TalkBack

TalkBack on Android

Before you start:
  • Enable TalkBack: Settings, Accessibility, TalkBack, Toggle ON
  • Open the Alt Text Playground in Chrome
  • Use reading controls to navigate by Images for efficient scanning
Essential gestures for image testing
ActionGesture
Navigate elementsSingle-finger swipe right (next) or left (previous)
Open reading controlsSwipe up then right
Set navigation to ImagesSwipe up then right, select Images
Navigate images onlySwipe right (next image) or left (previous image)
Activate elementDouble-tap anywhere
Pause speechTwo-finger single tap
1
No alt attribute
Playground Scenario 1
1
Open the playground in Chrome with TalkBack enabled.
2
Open reading controls: swipe up then right. Select Images. Swipe to Scenario 1's image.
3
Listen to what TalkBack announces.
Expected failure: TalkBack announces "unlabelled image" or a partial URI. No meaningful information about the image content.
2
Decorative image not suppressed
Playground Scenario 4
1
Set reading controls back to default. Swipe right through Scenario 4: paragraph, image, paragraph.
2
Listen to what TalkBack announces for the wave image between the two paragraphs.
Expected failure: TalkBack announces "decorative wave divider, image" between the two paragraphs. A decorative element should use alt="" to be silently skipped.
3
Functional image: alt describes appearance
Playground Scenario 5
1
Navigate to the cart icon link in Scenario 5. Swipe right until focus lands on it.
2
Listen to TalkBack's announcement. Ask: where does this link go?
Expected failure: TalkBack announces "shopping cart icon, link": appearance described, destination unknown. The user cannot make an informed decision about whether to activate it.
4
Correct alt text: all three types
Playground Scenario 8
1
Set reading controls to Images. Navigate through the three images in Scenario 8.
2
Listen to each announcement.
Expected pass: Meaningful image announces the full revenue data. Decorative wave is skipped silently. Cart icon link announces "Go to checkout, link." All three correct.
