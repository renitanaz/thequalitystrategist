A11y Test Playground

Alt Text Playground

Eight scenarios: six failures, one redundant case, and one passing example. Test with WAVE Images tab, axe DevTools, and a screen reader. Each scenario includes what NVDA announces so you know exactly what to listen for.

🎯 Open WAVE on this page and click the Images tab to see all eight scenarios mapped at once.
1
No alt attribute
Screen reader reads the filename. WAVE flags red.
What to do: Run WAVE or axe DevTools. Then use NVDA and Tab to the image. WCAG 1.1.1WAVEaxe DevTools

What to look for: WAVE flags with red error. axe flags image-alt violation. NVDA announces the filename.
Scenario 1: missing alt attribute

The image below has no alt attribute at all.

NVDA announces: "image.svg graphic" or the data URI: meaningless filename content
Fail WCAG 1.1.1 No alt attribute: WAVE red flag
2
Filename used as alt text
Has an alt attribute. Conveys nothing.
What to do: Inspect the image. Check the alt value. Run WAVE: yellow flag for suspicious alt. WCAG 1.1.1WAVE

What to look for: Alt value matches or resembles a filename. NVDA announces it as if it were a description.
Scenario 2: filename as alt text
NVDA announces: "IMG underscore 20241103 underscore 094512 dot jpg, graphic"
Fail WCAG 1.1.1 alt="IMG_20241103_094512.jpg"
3
Generic alt text
alt="image": the most useless alt text possible.
What to do: Inspect the image. Check the alt value. Tab to it with NVDA. WCAG 1.1.1WAVEaxe DevTools

What to look for: Alt value is "image", "photo", "graphic", or "icon". NVDA announces "image, graphic": the word image is announced twice.
Scenario 3: generic alt text
NVDA announces: "image, graphic": the word "image" twice, zero information
Fail WCAG 1.1.1 alt="image": redundant and meaningless
4
Decorative image without empty alt
Should be silent. Not silent.
What to do: Tab to the image with NVDA. Read the paragraph before and after it. WCAG 1.1.1

What to look for: The wave adds no information. But NVDA announces the alt text anyway, interrupting the reading flow.
Scenario 4: decorative image with non-empty alt

Our services have helped hundreds of teams ship better software.

We work with teams across product, engineering, and design.

NVDA announces: "decorative wave divider, graphic": interrupts reading flow for zero information
Fail WCAG 1.1.1 Should be alt="" not alt="decorative wave divider"
5
Functional image describes appearance, not action
Linked icon. Alt text tells you what it looks like, not where it goes.
What to do: Tab to the link below with NVDA. Listen to the announcement. WCAG 1.1.1 / 2.4.4NVDA

What to look for: NVDA announces the image description and "link": but the user cannot tell where the link goes.
Scenario 5: linked icon with appearance alt

Click the icon to proceed:

NVDA announces: "shopping cart icon, link": user has no idea the destination is checkout
Fail WCAG 1.1.1 / 2.4.4 Should be alt="Go to checkout"
6
Complex image with insufficient alt
Chart type named. Data not communicated.
What to do: Tab to the chart with NVDA. Ask: does the announcement give you the same information a sighted person gets? WCAG 1.1.1NVDA

What to look for: NVDA announces "bar chart, graphic": axe may not flag this as an error, but the user gets none of the data.
Scenario 6: chart with alt="bar chart"
NVDA announces: "bar chart, graphic": automation may pass this. A human reviewing knows the data is missing.
Fail WCAG 1.1.1 Automation blind spot: manual review required
7
Redundant alt text: repeated in adjacent heading
Not a WCAG failure. Poor experience.
What to do: Tab through the card below with NVDA. Count how many times the name is announced. Best practiceNVDA

What to look for: The name and role are announced twice in quick succession: once for the image, once for the heading.
Scenario 7: alt text duplicates adjacent heading

Sarah Chen, Lead Engineer

10 years of experience in quality engineering.

NVDA announces: "Sarah Chen, Lead Engineer, graphic" then immediately "Sarah Chen, Lead Engineer, heading level 3"
Redundant Not a WCAG fail Consider alt="" since heading provides full context
8
Correct alt text: the passing examples
Meaningful, decorative, and functional: all correct.
What to do: Run WAVE Images tab. Tab through with NVDA. Check each announcement. WCAG 1.1.1WAVENVDA

What to look for: Meaningful image announces useful data. Decorative image is skipped entirely. Functional image announces the action.
Scenario 8: correct alt text for all three types

Meaningful

NVDA announces: "Bar chart: revenue grew from £0.8M in Q1 to £2.4M in Q5, tripling over five quarters, graphic" ✓

Decorative

NVDA announces: nothing: image skipped entirely ✓

Functional

NVDA announces: "Go to checkout, link": destination clear ✓
Pass WCAG 1.1.1 Meaningful describes data · Decorative is silent · Functional describes action
