Broken heading hierarchy
H2 skipped, second H1, H4 without H3

What to look for: H1 jumps to H3 (no H2), a second H1 appears, then H4 appears with no H3. Three violations in one section.

3
Missing main landmark
Page content exists but no <main> wraps it.
What to do: Open WAVE Structure tab: no main landmark shown. Use NVDA: press Q to jump to main content. Nothing happens. WCAG 1.3.1WAVENVDA

What to look for: The section below is wrapped in a <div id="content"> instead of <main>. Screen reader users cannot jump directly to the main content area.
Scenario 3: div instead of main

Welcome

This section contains the primary page content but it is wrapped in a <div>, not a <main> element. The main landmark is missing.

A screen reader user pressing Q (NVDA) or using the landmark menu cannot jump directly here.

Fail WCAG 1.3.1 No main landmark: use <main> not <div>
4
Multiple nav elements without aria-label
Two navs. Both announced as "navigation". Indistinguishable.
What to do: Open WAVE Structure tab: both navs appear as "navigation" with no label. Use NVDA: press D to jump between landmarks. WCAG 1.3.1WAVENVDA

What to look for: Two nav elements below, neither has an aria-label. NVDA announces both as "navigation landmark": the user cannot tell which is the main nav and which is the breadcrumb.
