Design Phase Practice File

Six deliberate accessibility failures, each paired with its fix, matching the Blog 05 design-phase checklist. Import this file into Figma with the html.to.design plugin, then practise finding and correcting each issue with Stark, Adee, Color Blind, and the A11y Focus Orderer.

1. Colour Contrast

Fail

Lavender text on brand purple. Ratio 2.0:1. Required 4.5:1.

Pass

White text on the same brand purple. Ratio 4.9:1.

2. Focus Indicator

Fail

No focus state specified. Keyboard users cannot see where they are.

Pass

Explicit focus ring, 3:1 contrast against the background, offset from the button.

3. Tab Order Annotation

Fail
First name
 
Last name
 
Email address
 

No annotation. Developer guesses the sequence from layer order.

Pass
1First name
 
2Last name
 
3Email address
 

Every field numbered in reading order before handoff.

4. Touch Target Size

Fail

Icons sized 16x16px, matching the visible asset instead of the tappable area.

Pass

24x24px minimum target with spacing, even though the icon glyph itself is smaller.
