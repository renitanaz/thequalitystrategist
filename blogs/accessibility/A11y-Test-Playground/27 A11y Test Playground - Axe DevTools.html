A11y Test Playground

Axe DevTools Playground

Eight scenarios with deliberate violations. Install the axe DevTools Chrome extension, run a scan on this page, and match what axe reports against what you expect.

🎯 How to use: Open DevTools, go to the axe DevTools tab, click Analyse. Then work through each scenario and verify axe caught it: and check the incomplete list too.
1
Image missing alt text Critical
axe rule: image-alt · WCAG 1.1.1
What to find: Run axe. Look for a Critical violation under image-alt. Click the violation to highlight the element on the page.
Scenario 1: image with no alt attribute
axe should report: Critical: image-alt: "Image elements must have an alt attribute" on the img element above.
Critical WCAG 1.1.1 image-alt rule
2
Button with no accessible name Critical
axe rule: button-name · WCAG 4.1.2
What to find: Run axe. Find the Critical button-name violation. Click the element reference to highlight it.
Scenario 2: icon button with no label
Icon button: no aria-label, no visible text
axe should report: Critical: button-name: "Buttons must have discernible text"
Critical WCAG 4.1.2 button-name rule
3
Form input with no label Critical
axe rule: label · WCAG 1.3.1 / 3.3.2
What to find: Run axe. Look for the label rule Critical violation. Note the element selector axe provides.
Scenario 3: input with no associated label
axe should report: Critical: label: "Form elements must have labels"
Critical WCAG 1.3.1 label rule
4
Colour contrast failure Serious
axe rule: color-contrast · WCAG 1.4.3
What to find: Run axe. Find the color-contrast Serious violation. Note the exact ratio axe reports vs the required 4.5:1.
Scenario 4: text with insufficient contrast

This paragraph text is #9ca3af on white: approximately 2.85:1 contrast ratio. Fails WCAG 1.4.3 minimum of 4.5:1.

axe should report: Serious: color-contrast: ratio approximately 2.85:1, required 4.5:1
Serious WCAG 1.4.3 color-contrast rule
5
Invalid ARIA role Serious
axe rule: aria-roles · WCAG 4.1.2
What to find: Run axe. Find the aria-roles Serious violation. axe will show the invalid role value.
Scenario 5: element with invalid role value
This div has role="flyout" which is not a valid ARIA role. axe will flag this.
axe should report: Serious: aria-roles: "Role must be appropriate for the element"
Serious WCAG 4.1.2 aria-roles rule
6
Duplicate ID Moderate
axe rule: duplicate-id-aria · WCAG 4.1.1
What to find: Run axe. Find the duplicate-id violation. Note which elements share the same ID.
Scenario 6: two elements sharing the same ID
axe should report: Moderate: duplicate-id-aria: "IDs used in ARIA and labels must be unique"
Moderate WCAG 4.1.1 duplicate-id-aria rule
7
Incomplete: contrast on gradient background Incomplete
axe rule: color-contrast · requires manual check
What to find: Run axe. Check the Incomplete tab. This contrast check cannot be resolved automatically: axe flags it for manual review.
Scenario 7: text on gradient: axe cannot compute contrast

This text sits on a gradient background. axe cannot compute the contrast ratio automatically. It appears in the Incomplete list. You must check it manually using the eyedropper tool in DevTools.

axe Incomplete tab: color-contrast: "Element's background color could not be determined due to a CSS gradient"
Incomplete WCAG 1.4.3 Manual verification required
