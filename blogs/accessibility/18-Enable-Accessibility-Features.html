1. Why Setup Matters

Every QA tester who works on accessibility needs to know how to enable the key accessibility features on all four platforms before they start testing. Getting the settings wrong wastes time. Forgetting to turn a feature off between tests contaminates results. Knowing the fastest path to each setting is a professional skill.

This blog covers the essential settings for each platform: screen readers, display accommodations, font scaling, colour filters, keyboard access, and reduced motion. Each has a separate blog going deeper: this is the map.

Always test on a physical device. iOS Simulator and Android Emulator do not replicate screen reader behaviour, font scaling, or system-level accessibility settings accurately.

2. Windows

Windows 10 / 11 Narrator (built-in screen reader)
1
Enable: Win+Ctrl+Enter: toggles Narrator on and off instantly
2
Alternative path: Settings, Ease of Access (Win 10) or Accessibility (Win 11), Narrator, toggle ON
3
Note: Narrator is less comprehensive than NVDA for web testing. Use NVDA + Firefox for accurate results.
Windows NVDA (recommended for web testing)
1
Download: nvaccess.org/download: free, open source
2
Launch: Win+Alt+N or from the Start menu. NVDA announces "NVDA has started."
3
Stop: Insert+Q then Enter to confirm
4
Silence speech: Ctrl: stops current speech without closing NVDA
5
Recommended browser: Firefox for most accurate results. Chrome also supported.
Windows Display and colour settings
1
High Contrast: Alt+Shift+Print Screen: toggles High Contrast mode
2
Colour filters: Settings, Accessibility, Colour Filters. Options include Greyscale, Deuteranopia, Protanopia, Tritanopia
3
Text size: Settings, Accessibility, Text Size: drag slider to increase system text size
4
Reduce animations: Settings, Accessibility, Visual Effects, Animation Effects: toggle OFF
5
Keyboard access: Settings, Accessibility, Keyboard: Sticky Keys, Filter Keys, Toggle Keys all configurable here

3. Mac

macOS VoiceOver (built-in screen reader)
1
Enable/disable: Cmd+F5: toggles VoiceOver on and off
2
Alternative path: System Settings, Accessibility, VoiceOver, toggle ON
3
VO key: VoiceOver uses Ctrl+Option (referred to as VO throughout the series)
4
Silence speech: Ctrl: stops current announcement
5
Recommended browser: Safari. VoiceOver and Safari are tightly integrated on macOS.
6
VoiceOver Utility: VO+F8: opens preferences for verbosity, voice, and navigation settings
macOS Display and accessibility settings
1
Increase Contrast: System Settings, Accessibility, Display, Increase Contrast: toggle ON
2
Reduce Transparency: System Settings, Accessibility, Display, Reduce Transparency: toggle ON
3
Reduce Motion: System Settings, Accessibility, Display, Reduce Motion: toggle ON
4
Colour filters: System Settings, Accessibility, Display, Colour Filters. Greyscale, Protanopia, Deuteranopia, Tritanopia options available
5
Zoom: System Settings, Accessibility, Zoom: Use keyboard shortcuts to zoom or use scroll gesture with modifier key
6
Full Keyboard Access: System Settings, Accessibility, Keyboard, Full Keyboard Access: toggle ON to navigate all UI elements with Tab

4. iOS

iOS · iPadOS VoiceOver (built-in screen reader)
1
Enable: Settings, Accessibility, VoiceOver, toggle ON
2
Shortcut: Triple-click the side button (or Home button on older devices): if configured at Settings, Accessibility, Accessibility Shortcut, VoiceOver
3
Speech rate: Settings, Accessibility, VoiceOver, Speaking Rate: drag slider. Faster for experienced testers, slower when learning.
4
Recommended browser: Safari on a physical iPhone or iPad. Simulator does not replicate gesture behaviour.
iOS · iPadOS Display and accessibility settings
1
Larger Text: Settings, Accessibility, Display and Text Size, Larger Text: drag slider
2
Bold Text: Settings, Accessibility, Display and Text Size, Bold Text: toggle ON
3
Increase Contrast: Settings, Accessibility, Display and Text Size, Increase Contrast: toggle ON
4
Reduce Transparency: Settings, Accessibility, Display and Text Size, Reduce Transparency: toggle ON
5
Differentiate Without Colour: Settings, Accessibility, Display and Text Size, Differentiate Without Colour: toggle ON
6
Colour Filters: Settings, Accessibility, Display and Text Size, Colour Filters: toggle ON, then select Greyscale, Protanopia, Deuteranopia, or Tritanopia
7
Reduce Motion: Settings, Accessibility, Motion, Reduce Motion: toggle ON
8
Switch Control: Settings, Accessibility, Switch Control: for switch access testing

5. Android

Android TalkBack (built-in screen reader)
1
Enable: Settings, Accessibility, TalkBack, toggle ON. Confirm the dialog.
2
Shortcut: Hold both volume buttons simultaneously for 3 seconds: if enabled at Settings, Accessibility, TalkBack, TalkBack shortcut
3
Speech rate: Settings, Accessibility, TalkBack, Settings, Text to Speech: adjust rate
4
Recommended browser: Chrome on a physical Android device.
5
Note on Android versions: Settings paths vary by manufacturer. Samsung devices use Settings, Accessibility, Visibility Enhancements and TalkBack under Installed Services on some versions.
Android Display and accessibility settings
1
Font Size: Settings, Accessibility, Font Size: drag slider to largest
2
Display Size: Settings, Accessibility, Display Size: increase for larger UI elements
3
High Contrast Text: Settings, Accessibility, Display, High Contrast Text: toggle ON
4
Colour Correction: Settings, Accessibility, Colour and Motion, Colour Correction: toggle ON, select Deuteranomaly, Protanomaly, or Tritanomaly
5
Colour Inversion: Settings, Accessibility, Colour and Motion, Colour Inversion: toggle ON
6
Remove Animations: Settings, Accessibility, Remove Animations: toggle ON
7
Switch Access: Settings, Accessibility, Switch Access: for switch device testing
