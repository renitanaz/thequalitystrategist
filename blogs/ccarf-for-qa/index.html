CCAR-F for QA: what the blueprint actually asks of you

The Architect Foundations blueprint, read by someone whose job is to catch the risk, not ship it.

The Quality Strategist · Capsule hub · 6 min read

There is heavy CCAR-F prep content out there. There is heavy "AI for testers" content too. Let's connect the two.

Prep resources explain the blueprint for people shipping features: build the agent, wire the tool, ship the workflow. This capsule explains the same blueprint for the opposite job: verify the agent holds up, catch where the tool fails silently, refuse to sign off until it's proven itself.

The facts

Verified against the v1.0 exam guide, as of 16 August 2026.

Question styleScenario-based, one correct answer of four. Four scenarios drawn from a pool of six.

The registration gate

Stated early because it changes whether this capsule is even relevant to you: registration requires a work email on a domain tied to a Claude Partner Network organisation. A personal email won't get you in. If you're not sure your employer is on that list, that's worth confirming before you invest time in the rest of this capsule, not after.

What this capsule actually is

Five posts, five working deliverables, all built against PeakAndPack, the same demo app the Playwright and AI-Augmented QA series already use. Every post: one concept, one worked example, a boxed line tying it to the exact blueprint domain and weight, and a closing section naming what it doesn't solve. Under 8 minutes to read. Density from a quality seat is the actual differentiator.

Before you start: what you'll need

Every deliverable across this capsule assumes a repo with Claude Code running in it, not a real project. A throwaway folder works exactly the same. None of it needs PeakAndPack's actual source code either, that's not something you can clone, it's a live hosted demo (UI and API, both on Render), each post gives the URLs where they're actually needed.

If Claude Code isn't installed yet, the official docs cover that in a few minutes. Past that, each post has its own short setup section covering exactly where that post's specific files go, since the shape of the deliverables changes post to post.

What this hub does not solve

  • It does not get you registered if your organisation isn't on the Claude Partner Network.
  • It does not substitute for sitting the exam, or for hands-on time with Claude Code beyond what each post's worked example covers.
  • It does not carry the authority of a passed exam, only of a QA architect's read of a public blueprint, checked against official sources and an app you can go run yourself.
