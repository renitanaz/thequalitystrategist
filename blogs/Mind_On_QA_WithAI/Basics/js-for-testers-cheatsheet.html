Async & await Part 6

await page.click()Wait for it to finish, then carry on
Promise { <pending> }Printed? An await is missing
async ({ page }) => { }Needed to use await inside
Await: goto, click, fill, expect(locator), textContent, allNo await: building a locator, expect(value)
const r = page.waitForResponse(..); await btn.click(); await r;Start the wait before the action
try { await x; } catch (e) { }Not to hide a failing test step
for (const x of list) { await .. }In order. forEach doesn't wait
await Promise.all([a, b])Independent work, at the same time
