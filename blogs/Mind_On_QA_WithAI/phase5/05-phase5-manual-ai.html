Phase 5 of 8 · API Contract

API Contract, With a Reviewer Who Reads Fast

Paste the response, ask what's wrong. Cross-cutting issues surface faster than scanning by eye.

By RN ~4 min read Series: AI-Augmented QA
Manual, No AI Manual + AI Automated, Playwright AI QA Agent

Paste real API responses into Claude and ask it what's wrong with them. This catches contract violations that are easy to miss when you're just checking "did it return 200." Get the responses by calling the endpoints at https://peakandpackshopdemo.onrender.com (for example in Postman or curl), then paste what comes back.

What you actually do

  • Paste API responses into Claude and ask it to validate them against expected behavior
  • Ask Claude to write a contract spec from the Phase 1 requirements doc
  • Use Claude to identify missing validations and security issues you might not think to check

Prompts that actually work

Here is the response from GET /api/products. What contract violations do you see? [paste JSON]

Write an API contract spec for a shopping cart endpoint that adds items.

What security issues can you spot in this API response? [paste response with all users' orders]

What HTTP status codes should each of these scenarios return? [list scenarios]

This is how BUG-013 gets caught fastest. Paste the raw /api/orders response while logged in as one user, and ask Claude what looks wrong. A response containing multiple distinct user_id values when only one user is authenticated is an immediate, obvious flag, much faster than noticing it by manually cross-referencing IDs.

Your deliverable

One file: api-contract-ai-assisted.md, the contract spec and flagged violations, with your own confirmation of which flagged issues are real versus which need more context.

Time: ~1 hour. Faster than the manual pass specifically because spotting cross-cutting issues (like data exposure across multiple fields) is something Claude does well from a single pasted response.
