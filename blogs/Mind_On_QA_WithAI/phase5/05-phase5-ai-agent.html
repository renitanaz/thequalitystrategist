Phase 5 of 8 · API Contract

API Contract, All 11 Endpoints at Once

30-plus checks in under a minute. The bottleneck moves from running them to reading them.

By RN ~4 min read Series: AI-Augmented QA
Manual, No AI Manual + AI Automated, Playwright AI QA Agent

The agent calls every endpoint automatically, the same 11 checked manually in Approach A, but in seconds instead of hours, and flags every known bug with a severity rating attached.

Every call goes to the API base URL https://peakandpackshopdemo.onrender.com, the same host the manual and automated approaches use.

What the agent does

  1. Calls every endpoint automatically: happy path, wrong input, no auth, bad ID, where applicable
  2. Claude validates status codes, response schemas, error handling, and obvious security issues
  3. Flags all 11 known bugs with severity ratings, P0 through P3

Speed reveals the contract violations fastest here. Calling all 11 endpoints with all 4 scenarios each is 30+ individual checks. A human doing this manually (Approach A) takes 2-3 hours. The agent does the same calls in under a minute, the bottleneck shifts entirely to reviewing the output, not generating it.

What review still catches

Agent gets right
Status code mismatches, schema violations, and the obvious security issue (orders endpoint leaking other users' data), all grounded in actual responses it received.
Still needs a human check
Severity calls. A P0 vs P1 label is a judgment about business impact, not something derivable purely from the response shape.

Your deliverable

The API contract section of the agent report, all 11 endpoints checked, bugs flagged with severity, reviewed before being treated as final.

Time: ~10 minutes. By far the fastest of the four, and the volume of checks (30+) makes this the approach where speed matters most, a human alone wouldn't cover this much ground in the same session.
