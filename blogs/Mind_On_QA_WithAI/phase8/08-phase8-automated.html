Phase 8 of 8 · Reporting

The QA Report, Generated by Playwright

Run the suite. Open the HTML report. Every test, every failure, every trace.

By RN ~5 min read Series: AI-Augmented QA
Manual, No AI Manual + AI Automated, Playwright AI QA Agent

The automated report is what Playwright generates: an HTML report showing every test, its status, its duration, and (on failure) its trace, screenshot, and error message. This is not a substitute for a stakeholder summary, but it is the most detailed and accurate record of what the automated suite found.

Generating the full report

Run the complete test suite across all phases and generate the HTML report:

npx playwright test --reporter=html
npx playwright show-report

The report opens in a browser. Every test is listed. Green tests are passing. Red tests are the seven planted bugs. Click any failing test to see the exact assertion that failed, the full trace, and a screenshot of the page at the moment of failure.

What the report contains

SectionWhat it showsUseful for
Summary barTotal passed / failed / skipped, durationAt-a-glance health. 38 tests, 7 failing.
Test listEvery test, tag, file, duration, statusFinding the specific test that corresponds to a bug ID.

Video (if enabled)Full test session recordingUnderstanding intermittent failures.

Adding a structured summary alongside the HTML report

The HTML report is comprehensive but not skimmable. For a team standup or a stakeholder email, generate a JSON summary and format it:

npx playwright test --reporter=json > test-results.json

Then pipe it through a simple script to produce a plain-text summary:

node -e "
const r = require('./test-results.json');
const failed = r.suites.flatMap(s => s.specs).filter(t => t.ok === false);
console.log(failed.length + ' failing tests:');
failed.forEach(t => console.log('  FAIL:', t.title));
console.log(r.stats.expected + ' passing');
"

Your deliverable

Two files: the Playwright HTML report (generated by the suite) and qa-summary-automated.md — a one-page plain-text summary of the automated results, suitable for pasting into a team update or a Jira comment. The HTML report is the evidence; the markdown is the communication.

Time: ~60 seconds to run the suite and generate the report. The HTML report is instant. The markdown summary takes ~5 minutes to write from the JSON output.
