Phase 6 of 8 · E2E Flows

E2E Flows, Walked By Hand

Five journeys, one step at a time, documenting where reality and expectation diverge.

By RN ~5 min read Series: AI-Augmented QA
Manual, No AI Manual + AI Automated, Playwright AI QA Agent

Walk all 5 flows by hand, calling the API directly and clicking through the live UI, documenting actual versus expected at each step.

New to this? Phase 6 combines both earlier skills. If you're shaky on calling an API, read API Testing for Beginners; the flows here hit peakandpackshopdemo.onrender.com (API) and peakandpack-ui.onrender.com (UI).

The 5 flows, walked step by step

Flow 1: Browse and search

  1. Open the product list, verify items load
  2. Filter by category, verify only matching items show
  3. Search by term, verify matching results
  4. Sort by price, verify order is correct

Flow 2: Register new user

  1. Register with a new email, verify 201 and a token returned
  2. Register the same email again, verify 409

Flow 3: Login, add to cart, view cart

  1. Login, get a token
  2. Add an item to cart
  3. View cart, verify the item appears with the correct price

Flow 4: Checkout with discount code

  1. Complete Flow 3
  2. Apply SAVE10 at checkout
  3. Verify the total, expect 10% off, not 100%
  4. Verify the cart clears after checkout

Flow 5: Order history

  1. After checkout, view order history
  2. Verify the new order appears
  3. Verify only your own orders appear, not other users'

Flows 4 and 5 are where the known bugs surface end to end. Not as isolated API responses this time, but as the actual experience: a customer who applies a discount code and ends up with a free order, or who opens their order history and sees someone else's purchases. Walking the full flow makes the business impact concrete in a way an isolated endpoint test doesn't.

Your deliverable

One file: e2e-flows-manual.md, each of the 5 flows documented with actual versus expected results at every step.

Time: ~2 to 3 hours. Slower than testing endpoints in isolation, walking a full journey takes longer than checking one response, but it's the only approach so far that tells you what a real session actually feels like.
